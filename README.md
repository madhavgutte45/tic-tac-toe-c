# 🎮 Tic-Tac-Toe Game in C

A simple console-based Tic-Tac-Toe game developed using C programming.

## 🚀 Features

- Two-player gameplay
- Simple console interface
- Player turn management
- Win condition checking
- Draw condition checking
- Input handling

## 🛠️ Technologies Used

- C Programming
- Functions
- Arrays
- Loops
- Conditional Statements

## 📌 Project Overview

This project was developed to practice C programming fundamentals and problem-solving. The game allows two players to play Tic-Tac-Toe through a console interface while checking for winning and draw conditions.

## ▶️ How to Run

1. Install a C compiler.
2. Download or clone this repository.
3. Open the C source file in a C IDE.
4. Compile and run the program.
